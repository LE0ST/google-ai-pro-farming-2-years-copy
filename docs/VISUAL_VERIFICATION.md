# Visual evidence

Visual verification is an optional user-attested record kept separately from automatically parsed subscription evidence. A record may contain a claimed duration and the time it was entered. It does not establish eligibility, price, renewal date, or a future charge, and it never authorizes a subscription, cancellation, or payment operation.

The application labels this source `user_confirmed_visual_evidence` so it remains distinguishable from Google Play and Google One observations. Conflicts between visual and automatically parsed values stop the operational workflow for review.

Screenshots and account-specific notes can reveal private information. Keep them in the external data directory and review them before sharing. Test fixtures should use synthetic account and offer details.
